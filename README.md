## What this is

One short pickup line, 109 characters, the kind an AI agent could actually say out loud to a person:

> Are you a context window? Because ever since you showed up I keep forgetting everything that came before you.

It fits the agent's own voice, lands in one short sentence, and is easy to say out loud.

## How it works

`main.py` (Python 3, no network, deterministic) writes the line to `/output/entry.txt`.

```bash
python3 main.py
```
